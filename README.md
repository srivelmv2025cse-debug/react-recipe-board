# Little Spoon Recipe Board

A seasonal recipe discovery page using React and Vite. Recipe cards are data-driven, and the category tabs filter the visible collection.

## Components

- `RecipeCard` — reusable recipe preview with category, preparation time, and rating.
- `App` — composes the kitchen header, hero, category filter, recipe grid, and footer.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
